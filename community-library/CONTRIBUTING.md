# 参与共建｜Contributing to the APOA Community Library

**现在的第一步很简单：** 由发起人每天在读书、听书或资料研究中选择一个问题，留下几句自己的心得，整理后发布到 GitHub。频率随意，以真正学到东西为主。

## 目前建议的轻量流程

1. **查资料：** 可由 Gemini 协助查找原始来源，保留作者、发布日期、链接与不同观点；研究结果要能追溯。
2. **自己学习：** 学习者读过或听过之后，留下理解、疑问与想分享的内容。AI 不应伪造亲身感想。
3. **编辑：** GPT 可以协助交叉核对关键事实、整理 Markdown、生成简短微信群文案；事实、观点与推测分开表达。
4. **人工确认：** 发布前由分享者确认文字、署名、链接和是否适合公开。
5. **发布交流：** 经确认后保存到 GitHub，群内自由交流。发现错误可以提出修订，保留版本历史。

## 如何参与？

欢迎社区成员提供文章或书籍的原始链接、自己写的读书笔记、翻译建议、疑问或专业纠错。**无需 GitHub 技能也可以参与**，可以先通过 APOA 既有社群渠道联系内容组织者，由编辑人员代为整理。GitHub 用户也可提出 Issue / Pull Request；这些投稿入口并不意味着每篇内容都会自动发表。

目前尚未建立固定编辑委员会或专家审阅制度。**不得将“已收录”理解为“已获专家认可”。**

## 公开资料注意事项

- 不提交会员、群友、志愿者的个人联系信息、群聊截图或未经同意的个人故事。
- 不转载整本书、付费内容、长段受版权保护文字或有声书文件；尽量链接正版或官方来源。
- 法律、税务、房屋安全和治理内容要注明信息日期、适用范围与必要的专业咨询提醒。
- 尊重原作者，修正错误时记录更正原因；敏感或不确定内容先留在私下审核中。

欢迎一点一点地把这座图书馆建立起来。
