# 参与资料整理｜Source & Translation Contributions

## 第一阶段的编辑边界

APOA Community Library 目前先建设**原始权威资料索引与中英对照辅助译读**，而非观点文章、个人感悟、社群问答或 APOA 政策解读。

优先使用 ACNC、ASIC、ATO、AICD 等具名机构的官方公开材料，记录机构、英文标题、版本、原文 URL、章节位置、查阅日期和译文状态。

**引用资料与翻译时的基本要求：**

1. Gemini 可协助检索，但必须提供可打开的**原发布机构链接**；搜索摘要与 AI 生成文字不能冒充原文。
2. GPT 可协助整理和翻译，但需逐条核对引用的英文原句及限定条件，不能自行补充观点或将推测写成原机构立场。
3. 仅引用少量必要英文原文与对应译文；受版权保护的完整指南、整本书与整份报告均链接官方来源，不擅自转载或公开发布全本译文。
4. **中文为非官方辅助译文**。不要写成“ACNC 官方中文翻译”“AICD 官方中文版”，除非确有官方授权并可验证。
5. 遇到法律、税务、专业责任或特定机构资格，应保留资料的适用范围，不从通用指引推断 APOA 的具体状态。
6. 发布到 GitHub 草稿分支或 PR 后进行人工核对，再决定是否正式合并；发现错误用 GitHub 版本记录更正。
7. 不向公开仓库上传个人资料、未授权的群聊记录、访问凭据、未公开内部资料或受版权保护的完整作品。

## 编辑流程

**查找官方原始来源 → 记录版本与精确位置 → 选择合理范围的短篇原文节选 → 忠实中文翻译 → 人工核对 → GitHub 审阅 → 对外分享链接。**

第一阶段不要求每日更新。未来可以扩展到个人读书心得或社区讨论，但这类内容必须与目前的**原文与翻译资料栏目**分开，不能混入权威资料翻译中。

## 如何提交更正与材料？

熟悉 GitHub 的志愿者可通过 Issue 或 Pull Request 提供来源、更正或译文建议。不熟悉 GitHub 的参与者可以通过 APOA 既有社群渠道向内容组织者提供资料，由编辑人员协助整理。目前没有声称已建立正式专家审核委员会。

图书馆项目尚处于试行阶段；收录内容不表示原发布机构授权或 APOA 正式制度批准。
