# 读书与听书笔记｜Reading & Listening Notes

早晨用手机读几页书、听一段有声书，记录一个值得分享的观点。

这个书架从空白开始，**不规定书目、更新频率或统一读书进度**。之后可以陆续收录：

- 一段自己的阅读或听书心得
- 一份书籍介绍及正版阅读／收听渠道
- 一个想和大家讨论的问题
- 社区成员或专业人士推荐的延伸资料

请注明**书名、作者、版本（如已知）、合法来源链接**，区分书中的观点与自己的看法；不上传未经授权的完整电子书、有声书、长篇转载或受版权保护的扫描件。

可以从 [学习笔记模板](../templates/learning-note.md) 开始。欢迎未来将这里发展为面向整个社区的共读交流空间。
