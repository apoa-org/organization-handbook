APOA 编辑志愿者｜用 ChatGPT 直接向官网发稿

Publishing to the APOA Website with ChatGPT — A Guide for Volunteer Editors

APOA 社区图书馆 · 编辑协作实践2026.11.26 · V1.1（简明版）
中文朗读效果取决于设备和浏览器。

APOA 房主知识中心已经上线。现在，获授权的编辑志愿者可以用自己的 ChatGPT 协助写作、核查、翻译、保存草稿和发布官网文章，不必每次在后台复制粘贴。你负责内容和审核，AI 协助处理出版步骤。

个人授权 → 写稿核查 → 双语草稿 → 人工批准 → 发布验收

本篇讲的是 WordPress 官网发稿，与之前的 GitHub 图书馆出版指南是两条不同的出版路径。

01 / CONNECT

第一次准备：用自己的账号连接网站

请先向 APOA 网站管理员申请个人 WordPress 编辑账号，确认职责与权限。APOA 网站由自托管 WordPress 提供服务，并通过 Jetpack 与 WordPress.com 连接；不需要再为每位编辑安装网站插件。

  1. 注册或登录自己的 WordPress.com 账号，请管理员协助完成与 APOA 站点的 Jetpack 账号关联，确认你可以访问 apoa.org.au。
  2. 打开 WordPress.com 的 AI and MCP 设置，启用所需 MCP 访问，优先限定本站及内容读写工具；不要为了发稿申请管理员权限或开放无关工具。
  3. 在 ChatGPT 的插件目录（Plugins）中搜索 WordPress.com，安装官方插件，点击登录并授权。菜单名称可能随客户端变化；如手机端找不到，可以在网页端完成首次连接。
  4. 新对话可通过 @WordPress.com 选择已连接插件，然后先做只读测试。
复制给 ChatGPT：测试连接帮我看看 APOA 官网最近发了哪些文章，只看，不修改。

能读取文章不等于能写入或发布。投稿志愿者可以先申请仅限自己草稿的权限；正式编辑根据实际授权审核及发布。工具、套餐、账号权限和工作区配置以当时实际情况为准。

02 / SET UP

第一次对话：让 ChatGPT 认识 APOA

建议在 ChatGPT 中建立一个专门的「APOA 编辑」对话。第一次，把下面这段话和两个规范链接交给它就可以了。

你可以这样说以后你是我的 APOA 网站编辑助手。请先了解我们的发稿规范，帮我写稿、修改、翻译和发文。稿件由我审核，得到发布批准后再发。

官网出版操作规范
知识中心双语发稿规范

换一个新对话时，如果它不了解 APOA 的发稿规则，再把这两个链接给它。无法读取规范或连接网站时，请它告诉你，必要时请管理员协助。

03 / WRITE

平时写稿，就像聊天一样

你可以给 ChatGPT 一个想法、一篇新闻、一张获准使用的照片，或者自己写好的文章。比如：

我想写一篇关于澳洲出租房退租清洁的文章，你帮我查查资料，先写一稿。

看完初稿，哪里不满意就直接说：

标题再简单一点。
这里的法律依据再查一下。
加一个实际例子。
英文版也准备一下。

不需要背提示词，也不用学习技术术语。你最熟悉自己想表达什么，ChatGPT 负责协助整理。重要事实、专业判断、来源、隐私和版权仍需要人来核查。

04 / PUBLISH

审核通过，一句话发稿

如果想先在网站后台看看排版，直接说：

先存成官网中英文草稿，我看看。

两种语言的内容都确认无误，并且已经获得发布授权，就可以说：

审核通过，发吧。

ChatGPT 应按已了解的 APOA 规范处理查重、分类、署名、图片、语言互链、SEO 和发布检查。完成后，把真实的中英文文章链接交给你。如果操作失败或缺少权限，它应说明问题，而不是重复建稿或假装发稿成功。

没有发布权限的投稿志愿者，先把草稿交给正式编辑审核。需要分享时，也可以继续说：「帮我写一段微信群分享导语，加上文章链接。」Facebook 按既有规范和批准范围安排英文帖。

05 / KEEP IT SIMPLE

复杂的工作交给 AI，内容质量由人把关

编辑不需要记住八大分类的英文名称、网站技术字段或文章 ID。ChatGPT 应遵循规范并核对保存结果；适合长期查阅的知识稿归入房主知识中心，新闻、小报和社区动态留在相应频道。工具无法完成的步骤由编辑后台补齐。

我们希望每位志愿者都可以用自己习惯的语言写作和发稿。技术是为了减少工作，不是给编辑增加新的学习负担。

首次连接、草稿保存及发布能力取决于个人账号的实际授权；未经确认的内容不得公开。法律、税务、保险和工程安全等专业主题仍须适当的人工审核。
