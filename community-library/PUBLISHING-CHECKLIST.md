# APOA 社区图书馆｜上新与发布同步检查清单

> 2026-10-29 建立。适用于新文章、新书、章节更新、旧内容修订及下架。每次发布均应检查，不得只更新正文而漏掉入口。

## 核心规则

**一次上新 = 正文 + 目录 + 书架 + 首页相关位置 + 两分支发布 + 公开链接验收。**

按实际内容类型判断哪些入口应更新；没有变化的地方可标记“不适用”，但必须检查。保持已定稿的首页、书架 UI，不借上新重设计。

## 发布前与同步更新

- [ ] **内容正文**：更新 `main:community-library/reader/<slug>.html`，核查标题、正文、来源、免责声明、移动端、朗读和字号。
- [ ] **新书目录**：新书建立独立目录页，章节顺序和链接正确；已有书增加章节时同步更新书内目录、上一篇/下一篇等导航（如适用）。
- [ ] **主题书架**：更新 `main:community-library/reader/bookshelf.html`。新书成为独立馆藏；单篇文章归入合适的现有馆藏，不要只在书架外加一条临时推荐。
- [ ] **首页「最近更新」**：更新 `main:community-library/reader/index.html` 的最新文章、排序、摘要和日期。新内容排前面，保留合理数量的旧内容；仅改错别字等微调不必冒充新上架。
- [ ] **首页「书架里有什么／新书」**：新书加入首页馆藏入口；已有书新增章节时核对数量、描述及链接；不需要每篇文章都独立占一本书。
- [ ] **其他相关入口**：检查专题索引、导航、相关内容链接、书内链接、数量及展示文案，避免旧数字和失效链接。
- [ ] **内容状态**：导读已完成而其他章节仍在完善时，明确标注“持续完善”，不要把占位内容标成已完稿。

## 发布与验收

- [ ] **先更新 main**：正文、目录、书架、首页等相关源文件全部提交。
- [ ] **再同步 gh-pages**：对应 HTML 复制到 `gh-pages` 根目录，确认文件内容与 main 对应版本一致。
- [ ] **公开访问检查**：打开首页、书架、新书目录、新文章及返回链接；至少确认没有 404，移动端布局、朗读和字号功能未受影响。工具无法验证时明确告知用户，请用户协助验收，不得声称已验证。
- [ ] **交付说明**：列出本次新增/更新、GitHub 提交、公开链接、仍需检查的问题。

## 特别注意

1. **文章上新**：通常更新正文、所属书目录、书架章节列表、首页最近更新；首页新书区按需要更新。
2. **新书上架**：必须更新书的目录页、书架独立馆藏、首页新书入口；如属于最新发布，还要更新首页最近更新。
3. **旧文实质更新**：核对首页最近更新是否应显示“修订”，避免用旧发布日期误导读者。
4. **AI 应用知识**等专题：有新文章时归入已有馆藏，不要只显示在首页却遗漏书架。
5. **不自动公开**：用户要求草稿时只写草稿；用户明确要求发布或上架时，执行上述同步流程。

## 维护约定

每次发布前先阅读 `community-library/AGENTS.md` 和本清单。未来若变更网站结构或迁移仓库，应同时更新两个文件。
