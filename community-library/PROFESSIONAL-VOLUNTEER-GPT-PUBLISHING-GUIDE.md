# APOA 专业志愿者 GPT 写作与图书馆出版指南

**Professional Volunteers — AI Writing & Publishing Guide**  
**版本：** V0.2（试行）｜2026-11-07  
**适用：** APOA 社区图书馆、《澳洲房主生存手册》及相关专业知识专题

## 我们怎么一起写书？

法律、税务、保险、Tradie、物业管理等领域的专业志愿者，可以像现有图书馆编辑一样：**用自己的 ChatGPT 研究和写作；本人核查并明确批准；由获得写入授权的 GPT 工作流程直接更新 GitHub 和图书馆网页。**

不要求每个人学习编程、Issue 或 Pull Request；也不要求订阅某一档 ChatGPT 套餐。具体是否能直接写入，取决于所使用 ChatGPT 的工具功能及实际授权。

## 第一次使用：三个步骤

1. **注册 GitHub：** 在 https://github.com/signup 创建个人账号，建议启用双重身份验证。
2. **申请加入 APOA-org：** 将 GitHub 用户名交给 APOA 管理员，接受 [APOA-org](https://github.com/apoa-org) 组织邀请。管理员先确认职责，再为获授权者配置 `organization-handbook` 仓库的适当写入权限。**加入组织不等于自动拥有仓库写入权限。**
3. **连接自己的 ChatGPT：** 在账号中连接能够访问 GitHub 的相关工具，**实际测试读取和写入能力**。有的连接只支持读取，不能仅凭“已连接”假定 GPT 可以发布；如不具备写入能力，应由管理员协助完成可用的授权工作流。不要在聊天中发送密码、访问令牌或密钥。

## 第一次对话：把这段话复制给自己的 GPT

> 我是 APOA 社区图书馆获授权的专业志愿者，我负责【填写专业领域，如法律／税务／Tradie】。
>
> GitHub 仓库：https://github.com/apoa-org/organization-handbook
>
> 公开图书馆：https://apoa-org.github.io/organization-handbook/
>
> 请先读取仓库 `community-library/AGENTS.md`、`community-library/PUBLISHING-CHECKLIST.md` 和本指南，熟悉文章质量、来源、版权、排版和发布流程。先确认当前工具**是否真正有权读取和写入**所需仓库及分支；不要假设连接即意味着有权限。
>
> 之后协助我研究、撰写和修订【填写主题】。**先给我完整文章，由我进行专业核查并明确批准后，才能发布**。如获发布批准，请依规范更新 `main:community-library/reader/` 的源文件、相关目录和书架，再同步 `gh-pages` 根目录的公开页面，核查链接及手机阅读功能。不要擅自修改无关内容或覆盖他人的新更新。
>
> 发布完成后，请提供修改记录和正式阅读链接；做不到的步骤要如实说明，不能声称已上线。

## 平时怎么做？

**志愿者：** “我们写一篇维州出租房电气安全检查的文章。”

**GPT：** 查找相关官方资料，整理成普通房主能读懂的初稿，并保留来源、州别和核查日期。

**志愿者：** 根据专业知识修改、核实；确认无误后说：“这篇可以发布到 APOA 图书馆。”

**GPT：** 在工具有写入权限的前提下，遵循现有出版清单更新源文件、目录、书架及公开网站，检查结果并给出链接。遇到权限问题、内容冲突或无法核查之处，停止相应发布步骤并说明。

## 简单但必须遵守的原则

- **本人确认才发布。** GPT 是写作与发布助手，不是专业责任人；专业志愿者对自己确认的事实、解释和建议进行核查。
- **遵守专业边界。** 重要法律、税务、保险及维修安全结论须列出原始来源、适用州别和核查日期；不能用 AI 推测代替官方规定或持牌专业判断。
- **保护隐私和版权。** 不上传客户文件、个人住址、账单、群聊记录、密码或未经授权的内容。
- **协调并留痕。** 修改其他作者的内容前要先沟通；保留 GitHub 修改历史，不覆盖他人的最新工作。发布后发现问题继续修订。
- **保持网站完整。** 遵守 [AGENTS.md](AGENTS.md) 与 [PUBLISHING-CHECKLIST.md](PUBLISHING-CHECKLIST.md)；源文件在 `main`，网页在 `gh-pages`。不因为图方便而跳过目录与书架同步。

## 建议先试做

先邀请两三位专业志愿者，用自己熟悉的内容试运行，例如复核**住宅租赁法**、**Rooming House 地税**或**冰雹后的房屋安全**文章。先验证账户与授权是否可用，再从研究、核查到发布走完一次流程。

**目标很简单：各自用 GPT 写自己懂的内容，自己核查，获授权后直接出版；大家共同把《澳洲房主生存手册》越写越好。**
