# 🏆 APOA 全民房产知识挑战赛｜项目策划与招商合作方案

**英文暂定名称：** APOA Property Challenge  
**版本：** V0.1（公开策划草案）  
**记录日期：** 2026-11-01  
**状态：** 已整理策划构想，拟先试做线上版本；供志愿者讨论与潜在合作方初步沟通  
**策划主体：** APOA 澳洲房东联盟

> 本文件将脑力风暴整理为可讨论的策划草案，不表示游戏已经上线、志愿者已形成共识或合作已经落实。负责人、预算、赛程、奖项与招商权益仍待确认；任何品牌均不因被列入本文件而成为赞助商。

## 1. 项目概述

**网友出题、全民答题、线上常态化挑战、成熟后举办线下区域决赛。**

以房产知识、真实房价和家居维护为主题，用轻松的在线小游戏连接房东、其他房产持有者、专业人士和关注社区生活的居民。玩家既可以答题，也可以分享自己的经验、案例和题目；经过核实的内容逐渐形成 APOA 社区知识库。

**核心口号：你的经验，就是大家的知识！**

项目由三个可以独立参与的游戏组成：

| 项目 | 主要趣味 | 希望带来的价值 |
| --- | --- | --- |
| 谁是房产知识王？ | 快问快答，拼知识与反应 | 在轻松挑战中了解房产常识 |
| 猜房价小游戏 | 看照片、读线索、猜成交价 | 交流市场观察，享受揭晓答案的惊喜 |
| Handyman 知识大奖赛 | 识工具、看问题、选处理方式 | 学习实用的房屋维护与安全判断 |

三个项目不是同一套题目换名字：知识王突出快节奏，猜房价突出观察与判断，Handyman 突出生活实用性。初期可先推出其中一款，再逐步形成系列。

## 2. 希望实现什么

- **让知识变得好玩：** 不以考试为目标，而是让参与者愿意玩一局、再挑战一次，也愿意分享给朋友。
- **形成持续的社区互动：** 不只依靠大型活动当天的参与，而是探索全年可访问的线上游戏。
- **让成员成为贡献者：** 普通网友分享经验，专业人士贡献题目和解答，志愿者协助整理与核实。
- **连接本地社区：** 线上有了稳定参与后，探索地区决赛、现场互动和年度颁奖。
- **积累可复用内容：** 将核实后的题目与解释整理成知识卡片、社区话题和教育素材。
- **创造合作机会：** 用清楚的策划、可体验的游戏和真实成果寻找奖品、知识内容及活动支持。

中文参与体验可作为起点，英文版本作为后续可能方向，不要求首发同时完成双语。

## 3. 三款游戏的初步设计

### 3.1 谁是房产知识王？

**Property Knowledge Champion｜快问快答**

每轮用少量选择题、判断题或情景题形成短挑战。内容可以覆盖房产持有、物业管理、租赁常识、保险、税务基础、房屋安全和社区生活。

**一局的体验：** 开始挑战 → 连续答题 → 查看成绩 → 阅读简短解释 → 分享成绩或再来一局。

可以讨论的玩法包括限时答题、连续答对奖励、主题挑战周，以及普通网友与专业人士同场挑战。计分建议以正确率为主，用时为辅，避免为了抢速度牺牲阅读和判断；具体规则在试玩后确定。

涉及法规、税务或其他时效性知识，题目应明确适用地区、情景和核实日期。模棱两可、存在多个合理答案的内容不应直接作为淘汰题。

### 3.2 猜房价小游戏

**Guess the Property Price｜看房、看线索、猜价格**

展示已成交房产的获授权照片或可合法使用的示意素材，以及地区、户型、土地面积、成交时间等必要信息，让网友猜实际成交价。

**一局的体验：** 看房产信息 → 输入猜价或选择区间 → 揭晓成交价 → 看自己差多少 → 挑战下一套。

初期建议使用简单透明的偏差计分方式，并考虑按百分比误差比较不同价格房产，而不是只比较相差多少元。后续可尝试逐轮揭示线索、地区专场、猜高低和现场竞猜。

**公平与资料要求：** 明确成交价而非挂牌价，记录数据来源及成交日期；同一正式比赛的参赛者应获得相同信息。房源照片、户型图和文字不能因为可以在网上看到就默认可以转载。

### 3.3 Handyman 知识大奖赛

**Home Maintenance Challenge｜实用维护与安全判断**

用图文和简单情景考查工具识别、常见房屋问题、维修常识及安全判断。

**一局的体验：** 看问题图片或情景 → 选工具、选原因或选下一步 → 揭晓解释 → 学到一条实用知识。

可探索的题型包括“看图找问题”“认工具”“发现问题先做什么”“何时需要专业人员”。照片只能用于提出可能性和判断下一步，不能据此给出确定性的房屋诊断。

线下成熟后，可考虑工具辨认、无危险的模拟故障判断和专业人士演示。不设计带电、燃气、高处等危险操作挑战，也不以游戏代替持牌专业服务。

## 4. 核心特色：网友既答题，也出题

**投稿 → 初步整理 → 知识与素材核实 → 发布入库 → 网友挑战 → 解释与纠错 → 持续更新。**

普通网友可以贡献生活经验和真实问题；专业人士可以贡献领域知识。参与者不必会写完整试题，也可以先提交一个有意思的问题，再由志愿者协助整理。

### 投稿建议包含

- 题目或情景、选项、建议答案和简短解释；
- 可以核对的参考来源、适用地区及相关日期；
- 有权使用的照片或其他素材，以及明确的使用授权；
- 是否愿意署名，以及适合公开展示的昵称。

投稿联系方式如有必要收集，应留在受控的投稿管理空间，不写进公开题库或 GitHub。

### 出题者怎样获得认可

可以设置“优秀出题人”“知识贡献者”或月度“出题王”，与答题榜并行。奖励重点放在题目准确、有趣、解释清楚和帮助他人，而不是单纯比较投稿数量或故意把题出得很偏。

专业人士可以经同意署名，但贡献题目不等于 APOA 对其业务作担保。商业推广需要清楚区分，不能把广告包装成标准答案。

### 每道题都带走一点知识

日常练习结束后，给出简短知识卡片：正确答案、为什么、适用条件，以及必要的参考来源。涉及正式晋级的比赛，可在该场结束后再统一公布解答，减少提前泄题。

题目出现争议时，应允许反馈、暂时下架、复核和更正；必要时撤销问题题目的计分。

## 5. 赛事路径：先线上，后区域决赛

| 阶段 | 初步内容 | 推进条件 |
| --- | --- | --- |
| 线上试玩 | 一款小游戏、首批审核题目、结果解释、投稿入口 | 有可维护的玩法与题目 |
| 日常挑战 | 自由练习、定期更新、简单排行榜、分享 | 网友愿意复玩，志愿者能维护 |
| 月度活动 | 月榜、主题挑战、优秀出题人 | 基础规则稳定，有持续参与 |
| 地区决赛 | 在有参与者和组织者的地区举办现场赛 | 选拔规则、场地、人员及资源就绪 |
| 年度总决赛 | 与年会或其他大型社区活动结合 | 地区模式成熟后另行评估 |

**全年开放是方向，不等于现在承诺每月办赛或每个城市都举行决赛。**

平时练习可以宽松、鼓励学习；涉及晋级或实物奖品时，应另行设置可解释的正式比赛规则，包括重复参赛、查资料、同分、作弊与申诉处理。

网友出题者及审题者可能接触未公开答案，因此其参与正式计奖或晋级比赛时，应避免抽到自己提交、审核或提前知悉的题目；必要时使用独立比赛题池。

## 6. 第一阶段：先做出一个好玩的线上版本

建议先选一款最容易做出效果、也最容易取得可靠题目的游戏，而不是三款同时完整开发。

### 首发需要的基本体验

1. **手机可玩：** 进入页面即可理解玩法，完成一局并看到结果；可考虑免注册试玩。
2. **题目可信：** 少量经过审核的题目与解释，优先保证质量。
3. **愿意再玩：** 有“再来一局”和可分享的挑战链接。
4. **可以出题：** 网友投稿先进入人工审核，不自动公开。
5. **便于维护：** 志愿者能核对、批准、退回、修改和停用题目。

基础排行榜可在试玩规则稳定后加入；参与计奖或晋级时再明确所需账号及最低限度信息。第一阶段不预设收费，不依赖赞助款才允许启动。

优先评估能否复用 APOA 已有网站与游戏功能，但本策划不代表已经完成技术评估，也不自动生成开发工单。

### 暂时不做

复杂的跨游戏总积分、会员等级、全国报名系统、大量动画、自动发布网友投稿，以及没有相应管理能力的高价值奖品赛。

## 7. 志愿者与日常运营

让大家按兴趣认领小任务，不要求一位志愿者包办全部。

| 角色 | 可以参与的工作 |
| --- | --- |
| 出题伙伴 | 提供问题、案例、素材及参考答案 |
| 审题伙伴 | 核对正确性、适用条件、素材授权和解释 |
| 内容运营 | 选择本周挑战、整理纠错与反馈、分享知识卡片 |
| 技术伙伴 | 完善游戏、投稿及管理体验 |
| 地区伙伴 | 成熟后协助现场活动与地区决赛 |
| 合作联络 | 接洽奖品、专业内容或活动资源 |

正式试运行前，需要明确谁负责最终审题、处理反馈和维持题库更新。审核量过大时，可以限量收稿或放慢更新，不以牺牲质量换数量。

宣传可以围绕“你猜得对吗？”“你会先做什么？”“出一道能难倒朋友的题”，而不是只要求注册、转发和拉人。

## 8. 招商与合作思路

### 8.1 对合作方的一句话介绍

> APOA 拟以“房产知识王、猜房价、Handyman 知识挑战”连接社区，让网友在游戏中学习、贡献经验，并逐步发展本地线下决赛。我们希望寻找愿意支持社区教育的奖品、专业内容及活动伙伴。

策划草案可以支持早期接洽；试玩链接与真实反馈形成后，再补充更具体的合作条件。无需等到所有功能完成才谈合作，也不应在尚无数据时保证曝光或参与规模。

### 8.2 可供讨论的合作形式

| 合作形式 | 希望获得的支持 | 可讨论的回馈 |
| --- | --- | --- |
| 奖品支持 | 工具、礼品卡或适合活动的实物 | 经确认的鸣谢、奖项支持说明和成果反馈 |
| 知识合作 | 审题、讲解、专题教育内容 | 内容贡献署名、专业分享机会 |
| 地区活动支持 | 场地、物资、组织或演示资源 | 当地活动鸣谢和适当展示 |
| 系列合作 | 持续支持多期线上或线下活动 | 另行约定的系列合作权益与成果报告 |

以上是可洽谈选项，不是已经售出的赞助套餐。价格、冠名、排他性、标志位置、数量、期限及具体交付需另行确认，不在草案里承诺。

### 8.3 潜在合作对象

**Bunnings 是 Handyman 项目可以探索的潜在合作对象之一。** 可尝试询问本地门店是否愿意支持奖品、家居维护知识分享或地区活动；这里仅记录合作设想，不声称 APOA 已符合其某项资助资格，也没有已获赞助、礼品卡或场地支持的承诺。

其他可探索方向包括家居维护、建筑检查、工具、保险、物业管理及其他相关本地企业。题目与合作内容应符合 APOA 的教育目标，不因赞助而改变答案。

未经确认，不使用任何潜在伙伴的标志制造“已经合作”的印象。

### 8.4 招商材料需要讲清楚

- 活动是什么、面向谁、希望解决什么；
- 参与者具体怎样玩，以及目前是构想、试玩还是正式运行；
- APOA 已具备的能力与尚待完成的工作，均如实说明；
- 希望对方支持什么，APOA 能可靠交付什么；
- 已有数据、反馈及可以演示的成果；没有的项目标为待验证；
- 双方确认的奖品、露出、交付、取消与成果反馈安排。

对合作方只提供汇总成果，不默认交付参赛者个人名单或联系方式。任何营销订阅应与参赛分开征求同意。

## 9. 预算与资源怎么考虑

现阶段不写未经询价的总预算，也不把尚未落实的赞助当作收入。

| 资源项 | 起步时需明确的内容 |
| --- | --- |
| 技术与网站 | 现有功能能复用多少，新增开发与维护工作量 |
| 题库与审核 | 谁来出题、核实、整理素材及持续纠错 |
| 宣传素材 | 基础活动介绍、分享图和演示是否可内部完成 |
| 奖品 | 是否设置、来源、交付与可能运费；未落实不对外承诺 |
| 线下活动 | 场地、人员、物资、安全与必要保障，进入线下筹备时再预算 |

先明确首发范围、牵头人与可投入资源，再确认支出。初期可以不设置实物奖品，以好玩的体验和贡献认可验证参与意愿。

## 10. 内容质量、公平与公开边界

这些是实施前的检查事项，不构成对具体法律问题的结论：

- **知识与时效：** 法律、税务、保险和安全题须由合适人员核对，标明范围与日期，不用游戏答案替代个案意见。
- **素材与隐私：** 核实使用授权，移除私人信息；公开文件只放策划与适合公开的成果，不放投稿者联系方式、住址、聊天记录或私人群入口。
- **榜单与公平：** 区分练习和比赛，公布计分与申诉方式；不让已知答案的投稿、审核环节破坏正式赛公平。
- **奖品与规则：** 设置奖品或正式赛事前，核对活动覆盖地区的适用要求，完成规则审核；不把知识赛不经评估地改成随机抽奖。
- **安全：** 只设计适合公众参与的题目和演示，危险维修不作为动手竞赛。
- **商业独立性：** 署名、广告、赞助与知识解释清楚分开，不售卖答案或未经同意的参与者数据。

## 11. 用什么判断值得扩大

首发先收集简单、真实、可解释的数据，不预先宣称能够达到多少人。

| 观察项 | 想回答的问题 |
| --- | --- |
| 开始与完成一局的人数 | 玩法容易理解、愿意玩完吗？ |
| 再次参与情况 | 大家会回来吗？ |
| 分享带来的访问 | 是否愿意推荐给朋友？ |
| 投稿者与通过审核的题目数 | 社区共创能否持续？ |
| 纠错量与审核工作量 | 质量可靠吗，志愿者是否负担得起？ |
| 志愿者及合作意向 | 是否具备推出下一款或办地区赛的条件？ |

统计游戏次数时不将其冒充独立参赛人数；访问量、注册量和实际完成游戏的人数分别报告。小规模试玩也可以有价值，关键是如实说明。

## 12. 建议推进顺序与待讨论事项

**策划草案 → 志愿者讨论与分工 → 选第一款 → 准备题目和试玩 → 收集反馈 → 完善合作材料 → 逐步扩展。**

早期可拿策划与演示接洽潜在伙伴，取得真实参与数据后再谈更大的合作。线上玩法跑顺、志愿者有能力维护后，再决定月赛、地区赛及年度决赛。

需要讨论的核心问题是：先做哪一款；谁愿意牵头、出题或审题；首发能投入多少时间与资源；怎样兼顾轻松好玩和正式计奖公平。日期、奖品与参与门槛在这些基础明确后再定。

### 已有讨论方向

发起讨论者倾向“先做起来”，认可先线上、后线下区域决赛；三款游戏与网友出题是核心构想，希望以策划案推动志愿者参与和招商沟通。

**这不等于志愿者群已确认立项，也不表示赞助商已经同意合作。** 后续应把收到的建议、形成的共识和确定的安排分别补充，避免把设想写成已完成事实。
