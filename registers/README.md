# Registers

Indexes of projects, digital assets, official channels and accountable owners.

Record ownership and secure locations, not passwords or recovery credentials.

## Public digital asset records

- [APOA 数字资产公开登记表 V0.1](digital-assets-public-register.md) — 现有网站、域名、主机、邮箱、代码、组织资料及社区渠道；标记待核验事项，**不含账户凭据或个人资料**。
- [APOA 数字资产登记与交接清单 V0.1（讨论草案 PR）](https://github.com/apoa-org/organization-handbook/pull/13) — 交接原则和完整制度仍在讨论中，不代表已正式批准。

Private access details and recovery credentials must be maintained outside this public repository using approved controls.
